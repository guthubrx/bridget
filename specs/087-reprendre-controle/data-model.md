# Data Model: Reprendre le contrôle

## Entités

### ControlState (daemon, une ligne)

| Champ | Type | Règle |
|---|---|---|
| `paused` | bool | défaut `false` |
| `paused_since` | i64 epoch, nullable | posé à l'activation, effacé à la levée |
| `paused_by` | texte | principal humain (`humain` ou `cli:<user>`) |
| `pause_reason` | texte, nullable | libre, borné à 512 octets |
| `auto_objectives_cap` | u32 | défaut 5, borne 1..=100 |
| `generation` | u64 | incrémenté à chaque mutation ; une mutation porte `expected_generation` |
| `updated_at` | i64 | |

Invariants : une seule ligne (`id = 1`). Toute mutation écrit aussi une ligne `control_events`.

### ControlEvent (daemon, journal append-only)

`id, at, actor, kind ∈ {pause_on, pause_off, budget_set}, reason, generation_after`.

### HumanInboxItem (daemon)

| Champ | Type | Règle |
|---|---|---|
| `id` | texte UUID v4 | |
| `dedup_key` | texte, UNIQUE parmi les items ouverts | un dépôt sur une clé déjà ouverte rattache une occurrence, ne crée rien |
| `kind` | enum fermé | `intervention_required`, `chain_exhausted`, `review_verdict_pending`, `activation_approval`, `budget_reached`, `reply_debt`, `focus_waiting_agent`, `object_vanished`, `human_route_replaced` |
| `subject_ref` | JSON | `{objective_id?, delegation_id?, message_id?, project_id?}` |
| `context_json` | JSON borné 16 Kio | résumé lisible, historique des tentatives |
| `options_json` | JSON | décisions possibles, liste fermée fournie par le producteur, ex. `["reassign:<agent>", "cancel", "raise_budget", "ack"]` |
| `state` | enum | `open`, `resolved`, `closed_self` |
| `created_at`, `resolved_at` | i64 | |
| `occurrences` | u32 | incrémenté à chaque dépôt rattaché |
| `decision_json` | JSON, nullable | `{decision_id, choice, actor, at}` ; `decision_id` est un UUID v4 posé à la résolution |
| `producer` | enum | `daemon`, `maicie` |
| `acked_at` | i64, nullable | posé uniquement à réception de `HumanInboxAck { decision_id }` par le producteur, jamais à la relève |
| `notify_attempts_json` | JSON | `[ {at, ok, error?} ]`, borné aux 20 derniers |

Transitions : `open → resolved` (référent), `open → closed_self` (objet disparu, par le producteur). Aucun retour.

### FocusQueue (Maicie, migration v24)

`objective_id TEXT PRIMARY KEY, position INTEGER NOT NULL, opened_at INTEGER NOT NULL`. Position 0 = focus actif ; les autres en file. Invariant : au plus une ligne en position 0.

### HumanOriginConsumption (Maicie, migration v24)

`message_id TEXT PRIMARY KEY, objective_id TEXT NOT NULL, consumed_at INTEGER NOT NULL`. Une ligne par message humain ayant ouvert un objectif ; la présence rend `AttestationConsumption::AlreadyConsumed`.

### HumanDecisionApplied (Maicie, migration v24)

`decision_id TEXT PRIMARY KEY, item_id TEXT NOT NULL, applied_at INTEGER NOT NULL, effect TEXT NOT NULL`. Écrite dans la même transaction que l'effet de la décision ; sa présence rend la relève idempotente et conditionne l'envoi de `HumanInboxAck`.

### Objectif (Maicie, existant, payload JSON)

Ajout `focus: Option<{opened_at}>` dans le payload et `origin = HumanRequest {...}` pour un focus. L'état du focus est dérivé de `focus_queue`, jamais stocké deux fois.

### DelegateOrigin (protocole)

```
DelegateOrigin::Human {
  message_id: String,
  observed: { message_id, ts, sender, target, body },
  attestation: { version: 1, issuer_scope, canonical_request_sha256, signature }
}
```
Fabriqué uniquement par le daemon. Un client qui le fournit est refusé.

### RoutineOccurrence (Maicie, existant)

`state = Differee`, `reason ∈ {"pause", "focus", "budget", "controle_inconnu", "occurrence_vivante", …}`. Les quatre nouveaux motifs sont ajoutés au vocabulaire existant, pas à une nouvelle table ; `controle_inconnu` est rendu quand le daemon est injoignable à la relève et qu'aucun état de contrôle n'a pu être lu.

### ReductionReassignation (Maicie, existant)

Nouvelle variante `Differee { motif }` : aucune génération créée, épisode conservé. Le réducteur reçoit l'état de contrôle en entrée pure.

## Relations

```
ControlState 1 ── lu par ──▶ Maicie (chaque relève)   ▶ routines, réassignation, delegate
ControlState 1 ── lu par ──▶ daemon                     ▶ ronde, relances, `who`
HumanInboxItem * ── produit par ──▶ daemon | Maicie(notification_outbox)
HumanInboxItem.decision ── relevée par ──▶ Maicie (pull) ▶ appliquée à la délégation/objectif
FocusQueue.position 0 ── référence ──▶ Objectif(origin = HumanRequest)
HumanOriginConsumption.message_id ── référence ──▶ ledger daemon (message humain)
```

## Comptage du budget

`open_auto_generated_count = |{ o ∈ objectives : o.etat ∉ {Clos} ∧ o.origin = AutoGenerated }|`. Complexité O(n) sur les objectifs ouverts, n borné en pratique par `budget_cap + |focus_queue|`. `LegacyUnknown` ne compte pas : l'histoire inconnue reste inconnue (ADR-014).
