# Checklist qualité — Spec 020

## Contenu

- [x] La valeur et le défaut sont décrits sans imposer une interface produit.
- [x] La propriété transactionnelle est testable et non ambiguë.
- [x] Les scénarios couvrent branche neuve, force-push et multi-références.
- [x] Le nom de co-auteur utilisé par le témoin est inventé.
- [x] Les contrôles positifs empêchent un filtre trop large.
- [x] Les états indémontrables échouent fermés.
- [x] Une erreur du filtre est distincte d'une absence de co-autorat et refuse.
- [x] Les quatre causes fail-closed ont chacune un oracle et un mutant isolés.
- [x] L'échec de création du répertoire temporaire arrête le banc avant tout chemin dérivé.
- [x] Le runner arrête une fixture à sa première commande en erreur avant de la compter.
- [x] L'observation distante est indexée en O(U+R), sans rescan par mise à jour.
- [x] Une panne de l'indexeur distant refuse la transaction avec un diagnostic.
- [x] Les dépendances et le hors périmètre sont explicites.
- [x] Aucun marqueur de clarification ne subsiste.
- [x] Les critères de succès sont mesurables.
- [x] L'activation avant jury et merge est interdite.
