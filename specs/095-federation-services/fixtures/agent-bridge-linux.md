Ne pas exécuter bridge.sh, tmux ni l'ancien protocole Agent Bridge.
Lire la skill canonique : /home/moi/.local/lib/bridget-communication/skills/bridget/SKILL.md
Employer d'abord les outils MCP Bridget de la session ; un catalogue déjà vivant n'est pas rechargé par une installation de fichiers.
Le binaire courant est /home/moi/.local/bin/bridget ; le namespace client fédéré est /home/moi/.cache/bridget-core.
Ne pas démarrer de daemon ni changer de socket pour contourner une indisponibilité. Les UUID restent les adresses ; les noms sont cosmétiques.
