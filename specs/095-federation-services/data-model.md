# Données 095

Liaison : label technique, hôte/utilisateur/port SSH, clé privée et known_hosts existants, socket maître/racine, socket distante/racine. Toutes les valeurs sont explicites et validées.
Installation : copie privée du runner et paramètres inertes, définition native de service utilisateur, logs. Étapes : absent → installé → actif ; arrêt/échec observable ; retrait désactive uniquement l'installation possédée.
Socket distante : absente, vivante, périmée attestée ou inconnue. Seule absente/périmée attestée permet une acquisition ; une sonde ambiguë n'autorise aucune suppression.
