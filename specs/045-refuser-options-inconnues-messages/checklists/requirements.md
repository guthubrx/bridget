# Checklist de qualité — Session 045

## Contenu

- [x] Le besoin et le défaut mesuré sont distingués de l'implémentation.
- [x] Les scénarios sont compréhensibles et vérifiables.
- [x] Aucune clarification bloquante ne demeure.
- [x] Les dépendances et hypothèses sont déclarées.
- [x] Le périmètre exclut explicitement la cohérence entre options.

## Exigences

- [x] Chaque exigence possède un effet observable.
- [x] Le code de sortie et le message sérialisé sont tous deux exigés.
- [x] Le cas légitime d'un corps commençant par un tiret est couvert.
- [x] Les options connues privées de valeur sont distinguées du corps vide.
- [x] Les changements de comportement des appelants mesurés sont consignés.

## Préparation

- [x] La branche et le worktree sont isolés et publiés.
- [x] La base gelée et l'univers initial sont mesurés.
- [x] Les mutants attendus ciblent les gardes ajoutées, pas un ancien chemin.
