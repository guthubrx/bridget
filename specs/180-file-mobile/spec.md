# 180 — File de messages Android

Statut : In Progress. Correction du parcours mobile déjà demandé.

La flèche bleue enregistre le message. Si le destinataire travaille, Bridget le conserve dans sa file durable. Un volet avec compteur et chevron se trouve juste au-dessus de la saisie. Chaque message montre son texte et les icônes Modifier, Annuler et Transmettre maintenant. L’ancien lien avant envoi disparaît.

Les mutations ne concernent que les messages du téléphone associé et du destinataire autorisé, encore retenus. Une transmission commencée ne peut pas être présentée comme annulée. Les refus et issues inconnues restent visibles. La modification conserve la place et l’identifiant ; une révision concurrente est refusée. Les rejouements ne créent pas de second message.

Le téléphone montre immédiatement son enregistrement local puis l’état confirmé par Bridget. La file survit à une fermeture du téléphone. Quand l’agent est au repos, Bridget remet les messages dans l’ordre. Le bouton interruptif demande le guidage du tour actif et ne demande pas de redémarrage.

Recette : envoi normal pendant activité, volet replié/déplié, modification persistante, annulation réelle, promotion unique, échec réseau sans disparition ni doublon, clavier et retour dans le fil. Pixel physique requis pour les preuves complètes.
