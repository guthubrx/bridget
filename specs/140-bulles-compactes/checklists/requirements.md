# Qualité de la spec140

Ces cases évaluent les artefacts, pas les tests ou la livraison.

- [x] Le besoin utilisateur est explicite.
- [x] Le périmètre est autorisé et borné.
- [x] Les scénarios ont des résultats observables.
- [x] Les cinq familles sont nommées.
- [x] Le rendu des messages ordinaires est préservé.
- [x] Les libellés n'inventent pas une nature de mission.
- [x] Les noms absents ont un fallback honnête.
- [x] Le titre réel est facultatif et contrôlé par appartenance.
- [x] Les anciennes alertes restent compatibles sans migration.
- [x] Les détails conservent le texte intégral.
- [x] Copie, pièces jointes et actions restent inchangées.
- [x] L'accès clavier et le focus sont exigés.
- [x] Thèmes et largeur étroite sont vérifiables.
- [x] L'état par message/fil et la virtualisation sont couverts.
- [x] Les essais sont isolés et les exclusions explicites.
- [x] Les dépendances et critères de succès sont identifiés.
