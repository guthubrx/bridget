#249 — Guidage des briefs refusés

Parix reçoit brief_invalid sans cause lors d’une continuation existante. Les références file omettent host, obligatoire dans le validateur mais annoncé facultatif dans le schéma. Transmettre message et récupération dans detail pour les façades déjà ouvertes ; annoncer host/path obligatoires pour file. Un dossier absolu reste accepté. Aucun droit, plafond, lecture de source, admission ou rejeu métier ajouté. T3 reste ouvert.
