Correction demandée le25octobre2026. Statut : In Progress.

client externe n'apparaît que dans la documentation technique de son adaptateur.

l'autonomie comme une exception. Examiner guides, instructions, spécifications,
décisions et archives. Conserver les contrats d'adaptateur et leurs preuves exactes.

Acceptation : présentation native dans les deux langues ; consignes corrigées ;
recherche exhaustive des références restantes avec classement explicite ; liens
