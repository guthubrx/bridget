    CONNEXION

    Ajouter un serveur

    Identité SSH

    Bridget Desktop découvre le relais sur ce serveur puis ouvre son propre tunnel local temporaire.

    Utilisez 127.0.0.1 ou localhost et le port réellement exposé, par exemple 17893. Il peut venir d'un tunnel SSH déjà ouvert ou d'un autre chemin local. Bridget Desktop vérifie le relais avec son jeton sans chercher à connaître ce trajet.

    ENDPOINT

    Accès au relais

    Le relais Bridget est protégé. Son jeton reste seulement en mémoire pour cette connexion.
